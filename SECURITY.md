# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | :----------------: |
| 0.9.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities via public GitHub issues.

To report a vulnerability, please use **GitHub Private Vulnerability Reporting**:
1. Open https://github.com/muratboy/distronomad/security/advisories/new (or go to the repository's **Security** tab, select **Advisories** and click **Report a vulnerability**).
2. Provide detailed steps to reproduce the issue and any relevant system context.

Security reports will be reviewed promptly.
